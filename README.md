# 🚀 ProFile: Gen AI Interview Preparation Platform

A **full stack AI-powered web application** that helps users prepare for interviews by analyzing resumes, identifying skill gaps, and generating intelligent interview questions using Generative AI.

---

## ✨ Features

- 🔐 Secure Authentication (JWT + Token Blacklisting)
- 🤖 AI-powered Interview Question Generation (Gemini API)
- 📄 Resume Parsing & Skill Extraction
- 📊 AI-based Skill Gap Analysis
- 🧠 Personalized Interview Reports
- 📑 ATS-Optimized Resume Generation
- 🖨️ Dynamic PDF Creation using Puppeteer
- 🔒 Protected Routes & Session Handling
- ⚡ Scalable Backend Architecture

---

## ⚙️ Tech Stack

### 🖥️ Frontend
- React.js (Vite)
- Context API
- Custom Hooks
- SCSS

### 🔧 Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

### 🔐 Authentication
- JWT (JSON Web Tokens)
- Token Blacklisting

### 🤖 AI Integration
- Google Gemini API

### 📄 Other Tools
- Puppeteer (PDF Generation)
- Axios (API Calls)
